## Amendments (from Context Bundle)

- **AM-1 (Raw ChordPro Text Retention):** In `lib/data/database/app_database.dart`, the `hymns` table and database DAOs MUST persist and return the raw, unstripped `chordpro_body` text column alongside any pre-indexed lyrics.
